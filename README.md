# 股票池业绩跟踪看板

覆盖 20 家公司（美股 10 / A股 7 / 韩股 2 / 台股 1），汇总全球投行与国内券商对未来三年 EPS、PE、目标价的预测，支持 30/90/180 天窗口与机构范围筛选。

在线查看：https://tfassetmanagement.github.io/stockpool-dashboard/

数据来源：东方财富研报库与一致预期、同花顺 F10 盈利预测、Nasdaq 分析师一致预期、卖方研报正文（估值核心依据），以及人工维护的 Excel 底稿。

本仓库由脚本自动更新，每周五刷新一次。带 ᵈ 上标的是由现价÷EPS 等定义式推算得出，带 ᶜ 上标的是市场共识兜底值，均非机构原始披露。
